## لماذا وكيل؟

تطبيقات Claude وGemini الرسمية لا تعمل على أجهزة Mac القديمة. **وكيل** تطبيق أصلي صغير مكتوب بلغة Rust يعمل على:

- **Mac** بمعالج Intel بدءًا من **macOS 10.12 Sierra** (مثل MacBook Pro 2015 وما قبله)، وعلى أجهزة Apple silicon.
- **Windows** ‏64 بت.
- **Linux**.

لا يحتاج متصفحًا ولا Electron، ويرسم واجهته بـ OpenGL فيعمل على البطاقات الرسومية القديمة.

## ما الذي يقدمه

- **محادثة** مع Claude وGemini وOpenRouter (مئات النماذج، منها مجانية) وGroq وOllama على جهازك، وأي خدمة متوافقة مع OpenAI.
- **نماذج مجانية**: مفتاح Gemini مجاني، ونماذج OpenRouter المجانية (عليها علامة «مجاني»)، وOllama دون إنترنت.
- **وكلاء** لكل منهم تعليماته ونموذجه وأدواته: مساعد، كاتب، محلل، مقدّم عروض، باحث، أو وكيلك الخاص.
- **أدوات الوكلاء**: قراءة صفحات الويب، وقراءة الملفات وكتابتها في مجلد تختاره، والعمل داخل تطبيقات مكتب (كلمة وجدول وعرض ووثيقة) أو أي خادم MCP.
- **أنت تقرر**: يطلب الوكيل إذنك قبل أي تغيير (كتابة ملف أو تعديل مستند).
- **الكلفة ظاهرة**: عدد الرموز وتكلفة المحادثة بالدولار حين يكون السعر معروفًا.
- **مرفقات**: صور وPDF وملفات نصية.
- **تسع لغات**: العربية (الافتراضية، من اليمين لليسار)، English، Français، Español، Deutsch، Português، Türkçe، Bahasa Indonesia، اردو.
- **خصوصيتك**: مفاتيحك محفوظة في سلسلة مفاتيح النظام (Keychain على Mac، ومدير بيانات الاعتماد على Windows) ولا تُرسل إلا إلى الخدمة التابعة لها. لا حسابات ولا تتبع.

## البدء مجانًا

1. نزّل وكيل من [صفحة الإصدارات](../../releases/latest) أو من [mokteb.com](https://mokteb.com).
2. افتحه واختر **Gemini (مجاني)**، ثم اضغط «احصل على مفتاح» وانسخ المفتاح من Google AI Studio والصقه.
3. ابدأ الكتابة.

أو اختر **OpenRouter**، وفي نافذة اختيار النموذج فعّل «المجانية فقط».

على Mac: افتح ملف ‎`.dmg`‎ واسحب Agent AI إلى مجلد التطبيقات. التطبيق موقّع وموثّق من Apple.

## الوكلاء وتطبيقات مكتب

ثبّت كلمة أو جدول أو عرض أو وثيقة من [mokteb.com](https://mokteb.com)، فيجدها وكيل تلقائيًا. فعّل التطبيق للوكيل من **الإعدادات ← الوكلاء**، فيستطيع مثلًا «الكاتب» كتابة مستند في كلمة، و«المحلل» إنشاء جدول في جدول. ويمكن إضافة أي خادم MCP آخر من **الإعدادات ← التطبيقات**.

## Why Agent AI?

The official Claude and Gemini apps don't run on older Macs. **Agent AI** is a small native app written in Rust that runs on:

- **Intel Macs from macOS 10.12 Sierra** (a 2015 MacBook Pro and older), and Apple silicon Macs.
- **Windows** 64-bit.
- **Linux**.

No browser engine and no Electron. It draws with OpenGL, so it works on older graphics cards too.

## What it does

- **Chat** with Claude, Gemini, OpenRouter (hundreds of models, many free), Groq, Ollama on your own computer, and any OpenAI-compatible service.
- **Free models**: a free Gemini key, OpenRouter's free models (marked "free"), and Ollama offline.
- **Agents**, each with its own instructions, model and tools: Assistant, Writer, Analyst, Presenter, Researcher, or your own.
- **Agent tools**: read web pages, read and write files in a folder you choose, and work inside the مكتب apps (Kalima, Jadwal, Ard, Wathiqa) or any MCP server.
- **You decide**: an agent asks before it changes anything (writing a file, editing a document).
- **Costs in view**: tokens and the chat's cost in dollars when the price is known.
- **Attachments**: images, PDFs and text files.
- **Nine languages**: Arabic (the default, right to left), English, French, Spanish, German, Portuguese, Turkish, Indonesian and Urdu.
- **Private**: keys are kept in the system keychain (Keychain on Mac, Credential Manager on Windows) and only ever sent to their own service. No accounts, no tracking.

## Start for free

1. Download Agent AI from the [releases page](../../releases/latest) or [mokteb.com](https://mokteb.com).
2. Open it, choose **Gemini (free)**, press "Get a key", copy the key from Google AI Studio and paste it.
3. Start typing.

Or choose **OpenRouter** and tick "Free only" in the model picker.

On a Mac, open the `.dmg` and drag Agent AI to Applications. The app is signed and notarized by Apple.

## Agents and the مكتب apps

Install Kalima, Jadwal, Ard or Wathiqa from [mokteb.com](https://mokteb.com) and Agent AI finds them. Turn an app on for an agent in **Settings → Agents**: the Writer can then write a document in Kalima, the Analyst a sheet in Jadwal. Add any other MCP server in **Settings → Apps**.

## Build from source

```sh
cargo run --release -p agent-ai
```

Rust 1.95 or later. On Linux, install the development packages for X11/Wayland and xkbcommon
first (Debian/Ubuntu: `libxkbcommon-dev libwayland-dev libx11-dev libxcursor-dev libxrandr-dev libxi-dev`).

| Folder | What |
|---|---|
| `crates/agentai-core` | Providers (Claude, Gemini, OpenAI-compatible), streaming, the agent loop, tools (files, web, MCP), settings, chats, keys, translations |
| `apps/agent-ai` | The desktop app (egui) |
| `locales` | Interface translations, one `English<TAB>translation` file per language |
| `packaging` | macOS app bundle, signing and DMG |

Releases: a push to the `release` branch builds and publishes the macOS, Windows and Linux downloads.
